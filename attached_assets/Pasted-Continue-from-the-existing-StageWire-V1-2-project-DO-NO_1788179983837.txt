# STAGEWIRE V1.3 — REAL WORKDAY

The goal of V1.3 is simple:

**Help a stagehand before, during, and immediately after a real live-production call.**

The core StageWire workflow should now become:

**Get Call → Prepare → Arrive → Work → Finish Call → Call Receipt → Vault → Career Passport**

Keep everything mobile-first, fast, human, and worker-controlled.

---

# 1. UPGRADE CALL DETAILS

Create a proper Call Details screen.

A call should support:

* Show / event name
* Venue
* Venue address
* Date
* Scheduled call time
* Estimated end time optional
* Role / department
* Employer / labor provider optional
* Crew contact name optional
* Crew contact phone optional
* Parking instructions
* Crew entrance / load-in location
* Loading dock information optional
* Dress requirements
* PPE requirements
* Tool requirements
* General call notes
* Pay rate
* Pay type: hourly / day rate / flat rate
* Optional minimum hours / guarantee
* Call status

Use simple sections so a worker can find critical information quickly.

Important information such as venue, show, call time, and role should be visually prominent.

---

# 2. PRE-CALL CHECKLIST

Add a simple Pre-Call Checklist.

Provide sensible default stagehand items such as:

* Work gloves
* Crescent wrench
* Multitool
* Flashlight / headlamp
* Hard hat
* Safety vest
* Work boots
* Harness if required
* Water
* Phone charger
* ID / credentials

Allow the worker to:

* Check items off
* Add custom items
* Remove custom items
* Reset checklist
* Save checklist state for the individual call

Do NOT force every worker to use the same tools.

Different roles require different equipment.

Allow role-specific checklist suggestions without automatically claiming they are required.

---

# 3. ROLE-SPECIFIC CHECKLIST FOUNDATION

Create a simple foundation for role-specific suggestions.

Include at minimum:

* Stagehand
* Up Rigger
* Down Rigger
* Pusher
* Lighting
* Audio
* Video
* Carpentry
* Forklift / Lift
* Truck / Logistics
* Other

Examples:

An Up Rigger might need harness-related equipment.

A Pusher may need quick access to crew/logistics information.

Lighting, Audio, and Video workers may have different suggested tools.

These are SUGGESTIONS, not mandatory requirements.

Workers must remain able to customize their checklist.

---

# 4. ARRIVE AT CALL

Add a large:

**I'M HERE / ARRIVED**

action on the active call.

When tapped:

* Record arrival timestamp
* Update call status to Arrived
* Show the recorded arrival time
* Allow correction if accidentally tapped

Do NOT automatically start paid work time from arrival.

Arrival time and actual paid start time are different records.

---

# 5. ACTIVE CALL / WORK MODE

Create a simple Active Call screen designed for quick backstage use.

It should prominently show:

* Show/event
* Venue
* Role
* Scheduled call time
* Arrival time
* Actual work start if entered

Provide large quick actions:

* Add Note
* Add Photo placeholder
* Add Expense
* View Call Details
* View Checklist
* Finish Call

Do NOT clutter this screen.

A worker may be using this with gloves, one hand, poor lighting, or while exhausted.

* Work performed

# 10. SINGLE-SOURCE DATA RULE

This is extremely important.

Workers should NOT have to repeatedly enter the same information.

When Finish Call is completed:

Update the following from the same record:

* Call Receipt
* The Vault
* Career Passport experience
* Future Money/Taxes data source

Do not create duplicate disconnected copies of the same call.

The Call Receipt should be the permanent source record for completed work.

---

# 11. THE VAULT

Completed Call Receipts should automatically appear under:

**Vault → Work**

Notes, photos, receipts, and expenses associated with that call should remain attached to that work record.

Do not require the worker to manually add the completed call to The Vault.

---

# 12. CAREER PASSPORT

Preserve the worker-controlled Career Passport system from V1.2.

Completed calls may become eligible Career Passport experience.

The worker chooses whether each call appears.

Never automatically make work history public.

# 14. ACCESSIBILITY — NON-NEGOTIABLE

StageWire is being designed for actual stagehands.

Assume:

* Older workers
* Tired eyes
* Sunlight
* Dark backstage environments
* Gloves
* Dirty hands
* Scratched screens
* One-handed use
* Workers under time pressure

Maintain:

* Important show/venue information approximately 20–22px minimum
* Normal information approximately 17–18px minimum
* Secondary information approximately 16px minimum
* Buttons approximately 18–20px
* Tap targets minimum 48×48
* Strong contrast
* Visible focus states
* Proper form labels
* Human-readable errors
* Large-text mode
* Scroll instead of shrinking content
* No tiny gray text

Do not sacrifice readability just to fit everything on one screen.
